# 지질명소 발표 공방

고등학교 2학년 지구과학 수행평가 「국가지질공원의 지질학적 특징과 가치 소개하기」에서 쓰는 발표 자료 만들기 프로그램입니다.

학생이 활동지에 조사한 지질 명소 2곳의 내용(국가지질공원·명소, 위치, 형성 시기, 주요 암석, 지질학적 특징, 추론, 가치, 사진)과 비교·마무리 내용을 입력하고 **발표 자료 만들기**를 누르면, 정해진 틀에 맞춘 16:9 슬라이드 14장과 발표 대본 초안이 만들어집니다.

- PDF, PPT(슬라이드 노트에 대본 포함), 대본(.txt)으로 저장할 수 있습니다.
- AI를 쓰지 않으며, 입력한 내용은 학생 브라우저에만 저장되고 서버로 전송되지 않습니다.
- PPT·PDF 생성 도구가 파일 안에 들어 있어 인터넷이 막힌 환경에서도 저장됩니다.
